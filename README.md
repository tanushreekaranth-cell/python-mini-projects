Python Fundamentals Projects 🐍

A collection of beginner-friendly Python projects developed to practice and strengthen core Python programming concepts. These projects focus on improving problem-solving skills and building a solid programming foundation.

 📌 Projects Included

- 🧮 BMI Calculator
- 🍕 Pizza Order System
- 🏝️ Treasure Island Game
- 🎮 Hangman Game

 🚀 Concepts Covered

- Variables and Data Types
- User Input and Output
- Conditional Statements
- Loops
- Functions
- Lists
- Random Module
- String Manipulation

## 🛠️ Technologies Used

--jupyter notebook

 🎯 Purpose

These projects were built to revise Python fundamentals, improve logical thinking, and strengthen the foundation for Data Structures & Algorithms (DSA) and software development.
